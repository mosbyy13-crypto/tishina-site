Тишина Может Плакать — одностраничный сайт

Как открыть:
1. Распакуйте архив.
2. Откройте index.html в браузере.

Для публикации загрузите всю папку целиком на любой статический хостинг.

Структура:
- index.html — страница
- style.css — оформление
- script.js — фотогалерея
- assets/ — фотографии

Ссылки:
- Яндекс Музыка — прямая ссылка артиста
- VK — прямая ссылка сообщества
- Spotify и VK Музыка — сейчас ссылки на поиск по названию группы; заменяются в index.html при появлении точных URL.
